06 / QUESTIONS

Before you install.

Can I update it?

Regenerate it. Android can reuse the key; desktop builds do not auto-update.

How do I install it?

Android: allow unknown apps. Windows: run Setup. Linux: chmod the AppImage or extract the tar.

Do I need Chrome?

No. Android uses System WebView; desktop uses WebView2 or WebKitGTK.

Does it work offline?

No. It loads the live URL.

How is this different from PWABuilder or Bubblewrap?

PWABuilder and Bubblewrap build a Trusted Web Activity and usually need a cloud build or a local toolchain. URL to App patches a prebuilt WebView shell in the browser and signs the APK locally, with no account or server-side build.

Is it open source?

Yes. The Android, desktop and web sources are Apache-2.0 on GitHub.
