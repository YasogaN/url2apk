04 / DOESN'T

Not a browser.

  • Google sign-in fails in embedded WebViews.
  • No push, extensions or App Links.
  • No offline copy. It loads the live URL.
  • Some sites block WebView.

05 / PRIVACY

Your key stays here.

No account, no telemetry. The only third-party request is the optional favicon lookup.

  • The APK is assembled in this tab.
  • The key is non-exportable; the encrypted backup is the only copy you can move.
  • No analytics or third-party scripts.

06 / QUESTIONS

Before you install.

Can I update it?

Same key and a higher version code. Lose the key and you must uninstall.

How do I install it?

Allow unknown apps. Play Protect may warn.

Do I need Chrome?

No. It uses Android System WebView.

Does it work offline?

No. It loads the live URL.
