ANDROID

Website to Android APK, without a cloud build.

URL to App packages an HTTPS site as a small Android WebView APK in your browser tab. There is no account, no upload queue and no server-side build.

Why the cloud is optional

Most website-to-APK tools upload the URL to a server, build a wrapper there and send back an APK. That works, but it adds an account, a queue and a third party that sees your app. URL to App takes a different route: it ships a prebuilt WebView shell and patches the URL, name and icon locally.

The browser writes the app name into the binary manifest and resources.arsc, replaces the launcher PNGs, writes assets/config.json and builds the APK. It then generates a local RSA-2048 key with WebCrypto and signs the result with APK Signature Scheme v2. The private key never leaves the tab.

What the APK contains

  • A launcher icon, app-drawer entry and its own Android window.
  • Uploads, downloads, camera, microphone, geolocation and fullscreen video through System WebView.
  • A local error and retry screen, plus safe back navigation.
  • Your package name, your version code and your signature.

Install it

  1. Open the builder and paste a full HTTPS URL.
  2. Choose the app name and icon. The package name is derived from the domain.
  3. Generate the APK. The first build creates the backing key and downloads its encrypted .p1x backup.
  4. Allow unknown apps on the Android device and open the APK.

Keep the .p1x backup. Android identifies an app by package name and signing certificate, so the same key is what lets a later build install over the first one.

When not to use it

  • Google sign-in fails in embedded WebViews.
  • There is no offline copy; the app loads the live URL.
  • There is no Web Push, no browser extension support and no App Links.
  • Some sites deliberately block WebView, and DRM L1 or passkeys may be limited.
  • These are sideloaded personal builds, not Play Store submissions.

If you need a Trusted Web Activity, Play Store distribution or a full PWA install flow, PWABuilder or Bubblewrap are the better tools. Read the comparison before you choose.
